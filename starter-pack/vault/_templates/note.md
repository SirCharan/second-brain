# Human readable title

🟢 **active**

One paragraph stating the fact. One concept per note — if you are writing "and also", start a
second note and link the two.

> [!tip] Put the command, path, or number in a callout
> Callouts are what your eye finds when you reopen this in six months.

## Details

Link liberally with wikilinks. A link to a note that does not exist yet is fine — it marks
something worth writing.
