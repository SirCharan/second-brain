# Approved words + swap table

STE's full dictionary is ~900 approved words (one meaning each). This is a pragmatic core: prefer the short, plain, single-meaning verb; replace wordy or vague phrases.

## Approved plain verbs (use these)
Prefer the left column. Each has one clear meaning.

| Use | Instead of |
|---|---|
| use | utilize, leverage, employ |
| start | initiate, commence, kick off |
| stop / end | terminate, cease, halt (pick one and keep it) |
| make | facilitate, enable the creation of |
| show | display, surface, render (for text: "show") |
| get / read | retrieve, obtain, fetch (pick one per doc) |
| set | configure, establish, provision (when it means assign a value) |
| remove / delete | eliminate, purge (pick one; "delete" for data) |
| check | verify, validate, ensure (procedures: "verify") |
| fix | remediate, address, resolve |
| let | allow, permit, enable |
| do | perform, execute, carry out |
| find | locate, identify, discover |
| change | modify, alter, adjust (pick one per doc) |
| add | append, incorporate, introduce |
| send | transmit, dispatch, forward |

Rule: within one document, pick ONE verb per action and never swap to a synonym.

## Phrase swaps (kill wordiness)
| Don't write | Write |
|---|---|
| in order to | to |
| due to the fact that | because |
| at this point in time | now |
| in the event that | if |
| has the ability to | can |
| a large number of | many |
| in a timely manner | on time / within N seconds |
| prior to | before |
| subsequent to | after |
| with regard to | about / for |
| it is recommended that you | (imperative: just say the action) |
| please note that | (delete — state the fact) |
| in most cases | usually |

## Vague → concrete
| Vague | Concrete |
|---|---|
| quickly / fast | within N seconds |
| a while | N minutes |
| large / small file | file over/under N MB |
| if it fails | if the exit code is non-zero |
| some / several | the exact number |
| appropriate value | the value that … (state it) |
| various options | list the options |

## Words to avoid entirely in procedures
- Modals that hide the actor: "should", "would", "could" → use imperative or state the rule.
- "Basically", "simply", "just", "of course" → delete (they patronize and add nothing).
- "etc." in a procedure → list the items or say "the following:".
